Subject: Change request CR-01 from UAT

Hello,

During UAT the client asked for the following, which is not in the signed requirements:

> Can we also let patients log in with their national ID instead of the mobile number?

Closest requirement: REQ-01 (A patient logs in with a mobile number and a one-time code sent by SMS. The code expires after 5 minutes.)
Why it is a change: REQ-01 specifies login only by mobile number with an SMS one-time code, so adding national ID login is new functionality the baseline does not include.
Impact: Login screen (new national ID input and toggle, Arabic/English per REQ-11), authentication backend, and likely an integration with a national ID verification service. The SMS one-time code would need a mobile number linked to the ID, and patient data may need to store national ID. Medium effort, plus security and privacy review.

Please confirm whether to estimate it. No work starts before approval.
